# Amplify Configuration Setup

## Overview
This document explains how Amplify is configured in VidaBaile and how to fix authentication initialization errors.

## Synchronous Configuration Pattern (Current Implementation)

### Entry Point: `src/main.tsx`

The Amplify configuration happens **synchronously at the very top** of the application entry point, before any React rendering:

```typescript
// 1. Import outputs FIRST
import outputs from '../amplify_outputs.json';
import { Amplify } from 'aws-amplify';

// 2. Configure Amplify IMMEDIATELY (synchronously, before React)
Amplify.configure(outputs);

// 3. Only then import React and render the app
import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';
import App from './App.tsx';

// 4. Render the app
createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <App />
  </StrictMode>,
);
```

### Why Synchronous?

1. **Immediate Availability** — Cognito User Pool config is available to `<Authenticator>` immediately
2. **No Race Conditions** — No async initialization that could fail silently
3. **Clearer Intent** — The configuration requirement is explicit and cannot be missed
4. **Proper Error Handling** — If config fails, the entire app fails to load (correct behavior)

## Key Files

- **`src/main.tsx`** — Application entry point with Amplify configuration
- **`amplify_outputs.json`** — Generated by `ampx sandbox` in the project root
- **`tsconfig.app.json`** — Configured with `resolveJsonModule: true` to allow JSON imports
- **`scripts/copy-amplify-outputs.js`** — Helper script to copy outputs to public folder (for distribution builds)
- **`package.json`** — `dev` and `build` scripts call the copy helper

## Common Issues & Solutions

### Issue: "Auth UserPool not configured"

**Cause:** `amplify_outputs.json` not found or Amplify not configured at entry point.

**Solution:**
1. Ensure the backend is deployed: `npm run sandbox`
2. Verify `amplify_outputs.json` exists in project root
3. Check browser console for actual error
4. Hard refresh browser (Cmd+Shift+R on Mac)

### Issue: Amplify config imports fail at build time

**Cause:** TypeScript can't resolve JSON imports.

**Solution:** Verify `tsconfig.app.json` has:
```json
"resolveJsonModule": true,
"allowArbitraryExtensions": true
```

### Issue: Authenticator shows "Force change password" but then blank page

**Cause:** Usually the first login with temporary credentials from Cognito.

**Solution:** 
1. Complete the password change flow
2. Log out and log back in with new password
3. The app should proceed normally

## Development vs Production

### Development (npm run dev)
1. Runs `scripts/copy-amplify-outputs.js` to copy outputs to public folder
2. Vite serves files including the outputs
3. main.tsx imports directly from project root: `import outputs from '../amplify_outputs.json'`

### Production (npm run build)
1. Also runs the copy script
2. Built assets are in `dist/` folder
3. `amplify_outputs.json` is included in dist folder
4. Deployment should serve dist folder with all assets
